# Applying this repository update

## Current position

The connected GitHub account reported read access but no write access to Double-FW/Accessibility_Demographics on 14 November 2026. This update therefore has not been published. The existing MIT licence and Word report were inspected or identified and must be retained.

## Upload through GitHub

1. Open [Accessibility_Demographics](https://github.com/Double-FW/Accessibility_Demographics) while signed into an account with write access.
2. Extract the update ZIP on your computer. Open the extracted Accessibility_Demographics folder.
3. On the repository's main page choose **Add file → Upload files**.
4. Drag the **contents** of the extracted folder into the upload area, including the subfolders. Do not drag the enclosing Accessibility_Demographics folder itself, or the documents will be nested one level too deep.
5. Review the proposed files. README.md is intentionally replaced; LICENSE contains the same existing MIT text. The existing Apparent_Disability_Proportions_UK_Report.docx is not included and must not be deleted. The Markdown source copy lives separately under evidence/supplied/.
6. Use the commit message **Add accessibility demographics opportunity framework**. Commit to main if your normal workflow permits, or choose a new branch and open a pull request.
7. Open README.md and follow several links. Confirm AGENTS.md, LICENSE, index.json and the topic folders are present at the expected paths.
8. After publication, update CHANGELOG.md with the actual commit and publication date; remove the pending-publication note only when verified.

Alternatively, grant the connected GitHub account write access to this repository and ask for the prepared update to be published. No access token needs to be shared in chat. Access settings depend on how the GitHub connection is installed.

This package contains no executable agent, server or customer-data collection. Its guides and templates can be used directly in GitHub.
